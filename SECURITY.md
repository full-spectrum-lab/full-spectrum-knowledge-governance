# Security Policy

## Supported versions

No production version has been released. Security reports still receive coordinated handling.

## Reporting

Do not open a public issue containing credentials, private knowledge, personal data, unpublished enterprise information, exploit details, or sensitive source material. Contact the repository owner through a private Gitee channel.

## K0 security boundary

K0 is offline and uses only synthetic fixtures. It must not fetch network content, execute arbitrary expressions, load untrusted plugins, or include real regulatory or enterprise knowledge.
