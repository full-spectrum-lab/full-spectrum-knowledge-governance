# Contributing

The project is in K0 foundation development.

1. Open an issue describing the bounded change.
2. Preserve the project boundary and status vocabulary.
3. Add or update automated tests.
4. Do not add real private or regulated knowledge.
5. Do not modify Observer or Engine as part of this repository.
6. Attach build, test, schema, digest, and worktree evidence.
7. Do not describe `DESIGNED` or `IMPLEMENTED` work as released.
