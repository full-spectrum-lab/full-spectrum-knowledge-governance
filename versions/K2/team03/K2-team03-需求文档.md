# K2 team03 需求文档：真实来源适配器与动态来源治理

状态：`DESIGNED / NOT IMPLEMENTED / NOT RELEASED`

## 目标

在 `team02` 离线受控来源与快照切片之上，设计可插拔的真实来源适配器边界，使 RSS、HTTP API、HTML 和人工导入等来源能够被采集、标准化、快照化并纳入 K2 审计链。

## 范围

- 来源适配器注册、能力声明、身份与版本校验；
- 网络访问策略、超时、重试、速率限制和凭据隔离；
- 原始响应摘要、规范化内容、采集时间和请求元数据留存；
- `DYNAMIC_ONLY` 与 `HYBRID` 的候选快照和证据状态；
- 失败、超时、撤销、内容漂移和摘要不一致的 fail-closed 行为；
- 与 `team02` 快照、检索信封、审计回放契约兼容。

## 明确不包含

- 自动把动态材料晋级为 `FIXED_ONLY`；
- 自动发布、生产授权或跨企业共享；
- 修改 Observer v0.4、Engine 或 v0.2.1 冻结包；
- 默认开启网络访问；
- 以单次网络成功推断来源可信或生产可用。

## 进入条件

1. `team02` 保持 `ACCEPTED / VERIFIED LOCALLY`；
2. 适配器接口、证据模型和安全策略完成评审；
3. 提供完全离线的 fake adapter 和可重复 Golden；
4. 网络能力默认关闭，并有明确授权开关与审计字段。
