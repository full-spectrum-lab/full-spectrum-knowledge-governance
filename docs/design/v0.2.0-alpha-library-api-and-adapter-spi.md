# v0.2.0-alpha Library API and Adapter SPI

- Status: Implementation baseline
- Date: 2026-08-27
- Scope authority: `docs/planning/v0.2.0-alpha-scope-decision.md`

## Public contract

The Library accepts only explicit in-process values. No method searches for a
latest version, reads ambient product state, performs network I/O, or executes
a business action.

| Area | Operation | Required exact inputs | Output |
|---|---|---|---|
| Pack | Register/Get | ID + version; registration also requires declared bytes | `KnowledgePack` |
| Lifecycle | SubmitReview/Release | exact reference + actor + UTC time | current pack |
| Lifecycle | UpgradeContract | exact reference + target `knowledge-contract/1.1.0` + actor + UTC time | upgraded pack |
| Lifecycle | Supersede | exact source + exact released replacement + actor + UTC time | superseded source |
| Lifecycle | Tombstone | exact reference + non-empty reason + actor + UTC time | tombstoned pack |
| History | Audit/ReplayExact | exact reference; replay also requires owned audit sequence | immutable events/replay |
| Artifact | ReadArtifact | exact reference + artifact ID | verified bytes |
| Resolution | ResolveFixed | v1.0/v1.1 `FIXED_ONLY` request + explicit candidates | deterministic result |
| Evidence | BuildEvidence | exact stored result + expectations + explicit granularity map | immutable sidecar |

`KnowledgeReference` is ID plus semantic version. It never accepts `latest`.

## Lifecycle invariants

1. Register begins at `DRAFT`.
2. `DRAFT -> REVIEW_REQUIRED -> RELEASED` remains unchanged.
3. Complete Supersede is `RELEASED -> SUPERSEDED` and requires another exact,
   already `RELEASED` version of the same Knowledge ID.
4. Tombstone is a terminal transition from any existing non-tombstoned state,
   but requires contract v1.1.
5. Revoked, Superseded, and Tombstoned packs are excluded by `FIXED_ONLY`.
6. Artifacts and audit events are never mutated by a lifecycle transition.
7. Same-operation retries return the current pack only when recorded details
   match; conflicting retry details fail closed.

## Adapter SPI

`IFixedKnowledgeAdapter<TExternalRequest,TExternalResponse>` has exactly two
translation responsibilities:

1. `ToFixedCall` returns a `FixedKnowledgeCall` containing the public KG request
   and explicit candidates.
2. `FromFixedResult` converts a public `KnowledgeResolutionResult` to the
   caller's response type.

The Library extension method composes these translations with `ResolveFixed`.
The SPI does not own lifecycle, storage, evidence persistence, authorization,
or external action. The reference `ContractFixedKnowledgeAdapter` maps
`ContractFixedRequest` to `ContractFixedResponse` without data loss.

## Version behavior

- `knowledge-contract/1.0.0`: preserved baseline; no Tombstone value.
- `knowledge-contract/1.1.0`: additive fixed-lifecycle contract with Tombstone.
- A resolver accepts v1.0 and v1.1 fixed requests and preserves the request
  contract version in the result.
- Unknown contract versions fail closed.

## Explicitly absent

HTTP, MCP, UI, Worker, LLM, vector/search, dynamic acquisition,
`DYNAMIC_ONLY`, `HYBRID`, Observer/Engine references, Skill-specific behavior,
and production authorization are not part of this contract.
