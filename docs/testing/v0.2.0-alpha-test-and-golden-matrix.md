## Compatibility evidence

`docs/compatibility/v0.1.x-baseline-sha256.json` freezes the released v1.0
schema and synthetic Golden inputs/outputs used by this repository. The v0.2
gate recomputes every digest. The manifest does not claim that later files were
part of the original public package; each entry includes its evidence role.

The existing SQLite layout remains at `PRAGMA user_version=3`. Compatibility is
proved by creating v1.0 data, closing it, reopening it through v0.2, and reading
the exact pack, artifact, audit, result and evidence. No destructive migration
is permitted.

## Gate result vocabulary

- `PASS`: command ran and evidence matched.
- `FAIL`: command ran and evidence did not match.
- `NOT_EXECUTED`: environment did not execute the check.
- `UNKNOWN`: evidence is insufficient.

`KG_V0_2_INTERNAL_ENGINEERING_PASS` requires every required local check to
PASS and an independent re-verification. It does not imply release, external
pilot acceptance, production readiness, or deployment.
