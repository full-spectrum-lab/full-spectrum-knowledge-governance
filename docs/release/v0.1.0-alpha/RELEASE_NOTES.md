# v0.1.0-alpha release notes

Technical preview of the local-first fixed-knowledge governance kernel.

Included: contracts and identifiers, SQLite registry, immutable artifact store, lifecycle audit/replay, fail-closed FIXED_ONLY resolution, trace and coverage evidence, released domain profiles, taxonomy, slots, exact bindings and deterministic planning.

Validation baseline: 70/70 tests, 12 Draft 2020-12 schemas, five independently retested K0 stages and KG0 Final Gate PASS.

Known limits: Windows is verified; Linux/macOS are not executed. No dynamic retrieval, LLM, vector database, Skill, Observer/Engine adapter, real regulatory knowledge or production deployment is included.
