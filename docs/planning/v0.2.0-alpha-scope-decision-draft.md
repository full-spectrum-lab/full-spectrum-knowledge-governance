# v0.2.0-alpha scope decision draft

Status: `DRAFT / NOT APPROVED`

The existing roadmap assigns v0.2.0-alpha to K1 fixed-knowledge lifecycle completion. The proposed stable call boundary is compatible with that goal and should not replace it.

Recommended combined scope:

1. complete Supersede, Tombstone and historical Replay semantics;
2. freeze a narrow library API and Adapter SPI around FIXED_ONLY requests, results and evidence;
3. provide an in-process reference adapter and contract tests;
4. retain zero dependencies on Observer, Engine, LLM, vector databases, dynamic retrieval and UI;
5. add compatibility and upgrade gates from v0.1.x.

The version proves that an external system can call the fixed governance kernel through a stable, testable boundary while the lifecycle remains auditable. It does not begin K2 dynamic evidence work.

Approval is required before this draft changes the formal Wiki roadmap.
