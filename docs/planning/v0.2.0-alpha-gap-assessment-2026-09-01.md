# KG v0.2.0-alpha Gap Assessment

Date: 2026-09-01

## Verified baseline

- Isolated .NET SDK `10.0.301` installed outside the repository.
- Locked restore and Release build: `PASS`.
- Full test suite: `76/76 PASS`.
- K0-05 verification gate: `PASS`.
- Existing lifecycle states are the frozen five-state contract: `DRAFT`, `REVIEW_REQUIRED`, `RELEASED`, `SUPERSEDED`, `REVOKED`.
- Supersede, revoke, audit recording, and historical replay are already implemented and tested.

## Scope decision

Do not add a new `TOMBSTONE` lifecycle state in v0.2.0-alpha without a separately approved contract change. The current five-state enum is part of the K0 compatibility surface; adding a state would require schema, replay, migration, and independent acceptance updates.

## Remaining K1 work

1. Freeze a narrow `FIXED_ONLY` library call boundary and document input/output/error invariants.
2. Define an in-process Adapter SPI that remains independent from Observer internals and Engine execution.
3. Add contract tests for success, missing Slot, ambiguity, version mismatch, and fail-closed behavior.
4. Add v0.1.x compatibility fixtures covering unknown fields, schema version rejection, rollback, and replay.
5. Produce machine-readable evidence and a candidate package only after the above gates pass.

## Deferred

DynamicOnly, Hybrid, dynamic retrieval, LLM, vector databases, Skill Runtime, real enterprise knowledge, production authorization, and direct Observer/Engine coupling remain deferred.
