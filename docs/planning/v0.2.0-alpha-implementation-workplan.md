# KG v0.2.0-alpha Implementation Workplan

Status: `OWNER-AUTHORIZED WORKING PLAN`; the formal roadmap and existing ADRs remain unchanged.

## Goal

Complete the fixed-knowledge lifecycle and stabilize a narrow external call boundary without introducing DynamicOnly, Hybrid, LLM, vector retrieval, UI, or Observer/Engine coupling.

## Work packages

### K1-Lifecycle

- Implement and test Supersede and Tombstone transitions.
- Preserve immutable released artifacts and append-only audit events.
- Add historical Replay fixtures for valid and rejected transitions.
- Verify deterministic state and audit-head reconstruction after replay.

### K1-API

- Freeze the narrow `FIXED_ONLY` request/result/evidence contract.
- Define the in-process Adapter SPI without depending on Observer internals.
- Add a reference Adapter and contract tests for success, missing Slot, mismatch, and fail-closed paths.

### K1-Compatibility

- Define v0.1.x to v0.2.0-alpha compatibility cases.
- Test unknown-field preservation, schema version rejection, rollback, and replay of old records.
- Record machine-readable evidence for every compatibility decision.

### K1-Release

- Run the full regression gate from a clean clone.
- Build a Windows x64 candidate with manifest, SBOM, checksums, and boundary declaration.
- Obtain independent re-verification before any release decision.

## Explicit non-goals

DynamicOnly, Hybrid, dynamic retrieval, LLM, vector databases, Skill Runtime, production authorization, real enterprise knowledge, and direct Observer/Engine integration remain deferred.

## Exit criteria

All K1 tests pass; lifecycle replay and audit evidence are deterministic; the Adapter contract is documented and tested; compatibility gates pass; the candidate remains `PRODUCTION_READY=NO` until external gates are separately satisfied.
